# WinKu 小账本 1.0 验证记录

开发环境：Windows；安卓模拟器 API 36，390×844 逻辑像素。所有交易数据均为专门构造的合成通知，未连接用户手机或真实支付账户。

- 22 个 Java 通知解析用例通过。
- 20 个金额算式解析用例通过。
- 16 项 SQLite / 后台数据通路断言通过。
- 端到端验证通过：后台界面进程关闭后继续采集、重复事件不重复入账、明确支出自动记账、未确认转账留待核对、普通聊天不自动入账、重启解锁后不用打开账本即可恢复采集。
- WebView / CSP / SQLite 的完整手动记账路径验证通过：输入 `35+12.5`，保存后数据库金额为 47.50，表单正常关闭。
- 发布 APK 已在模拟器全新安装并验证启动；发布构建的后台通知入账验证通过。签名 v2/v3 校验通过；声明的普通权限仅 RECEIVE_BOOT_COMPLETED，通知读取使用系统单独授权。
- Android release Lint 通过，保留目标 SDK 36 与界面有意启用 JavaScript 的提示。
- UI 独立复查结果：此前按钮触控面积、文字对比度和大字体截图问题均已解决。此结论仅覆盖所列 UI 问题。
- Android 模拟器真实截图已覆盖浅色、深色、自动记账、明细、设置以及 1.3 倍字体下的设置、平台、通知收件箱和展开说明。截图没有使用浏览器模拟。

后台内存观测：调试构建采集进程约 24 MB PSS；发布构建一次观测约 6.2 MB PSS，两次均为 0 Activities / 0 WebViews。数值受系统共享内存、GC、采样时机等影响，不能作为真机内存或续航保证。未进行长期耗电测试。

未验证：用户手机厂商的后台策略、实际微信/支付宝/云闪付各版本的通知模板覆盖率，以及完全不漏账。平台不提供的通知内容无法由本 App 补出。

完整账本和通知收件箱保存在应用私有 SQLite 数据库；交付安装包不含测试流水。首次安装为空账本。
